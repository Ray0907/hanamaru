Graceful fallbacks

Without ResizeObserver, use window resize plus explicit refresh(). Without IntersectionObserver, viewport triggers degrade to load. Without the Web Animations API, CSS animation and elapsed-time accounting remain. The CSS Highlight API is not required because Range geometry renders through SVG.

Explicit V1 limitations

No cross-document or cross-shadow-root ranges, editable-document authoring, persistence, collaboration, image annotation, or arbitrary drag positioning.

Quick start

Load the public stylesheet and module, then choose when Hanamaru scans. Nothing runs merely because the script arrived. 

<link rel="stylesheet" href="./dist/hanamaru.css">
<script type="module">
  import { scan } from './dist/hanamaru.esm.js'
  scan()
</script>
